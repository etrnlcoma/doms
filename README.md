# doms

Пока что здесь выложено первое задание по РОМС.

Чтобы запустить код у себя, нужно скорпировать репозиторий, создать conda - окружение с пайтон 3.12

```
conda create -n mujoco python=3.12
conda activate mujoco
```

После скачиваете зависимости и запускаете код

```
cd doms/Task1
pip install -r requirements.txt
python optimize.py
```
